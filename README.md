# Chat With PDF 📄

**Chat With PDF** — Powered by LangChain + Streamlit — lets you upload a PDF and interactively chat with its contents. Ask questions, get summaries or extract information without reading the entire document manually.

---

## Features

- **PDF Upload** – Upload any PDF document to the app.  
- **Text Extraction & Processing** – Extract text from PDF, split into manageable chunks, and prepare for retrieval & generation.  
- **Conversational Interface** – Ask questions in natural language about the PDF content and receive context-aware responses.  
- **Real-time Chat** – Get instant answers powered by a large language model + retrieval of relevant text segments.  
- **Minimal Setup** – Pure Python + Streamlit; easy to install and run locally.  

---

## Tech Stack

- Python  
- LangChain (for document-text retrieval + LLM integration)  
- Streamlit (for web UI)
